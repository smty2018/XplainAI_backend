# v0.1.0 ¶

Date : October 21, 2020

This is the first release of manimce after forking from 3b1b/manim.  As such,
developers have focused on cleaning up and refactoring the codebase while still
maintaining backwards compatibility wherever possible.

## New Features ¶

### Command line ¶

1. Output of ‘manim –help’ has been improved
1. Implement logging with the rich library and a logger object instead of plain ol’ prints
1. Added a flag --dry_run , which doesn’t write any media
1. Allow for running manim with python3 -m manim
1. Refactored Tex Template management. You can now use custom templates with command line args using --tex_template !
1. Re-add --save_frames flag, which will save each frame as a png
1. Re-introduce manim feature that allows you to type manim code in stdin if you pass a minus sign (-) as filename
1. Added the --custom_folders flag which yields a simpler output folder structure
1. Re-implement GIF export with the -i flag (using this flag outputs ONLY a .gif file, and no .mp4 file)
1. Added a --verbose flag
1. You can save the logs to a file by using --log_to_file
1. Read tex_template from config file if not specified by --tex_template .
1. Add experimental javascript rendering with --use_js_renderer
1. Add -q/--quality [k|p|h|m|l] flag and removed -m/-l flags.
1. Removed --sound flag

### Config system ¶

1. Implement a manim.cfg config file system, that consolidates the global configuration, the command line argument parsing, and some of the constants defined in constants.py
1. Added utilities for manipulating Manim’s .cfg files.
1. Added a subcommand structure for easier use of utilities managing .cfg files
1. Also some variables have been moved from constants.py to the new config system: FRAME_HEIGHT to config["frame_width"] TOP to config["frame_height"] / 2 * UP BOTTOM to config["frame_height"] / 2 * DOWN LEFT_SIDE to config["frame_width"] / 2 * LEFT RIGHT_SIDE to config["frame_width"] / 2 * RIGHT self.camera.frame_rate to config["frame_rate"]

### Mobjects, Scenes, and Animations ¶

1. Add customizable left and right bracket for Matrix mobject and set_row_colors method for matrix mobject
1. Add AddTeXLetterByLetter animation
1. Enhanced GraphScene You can now add arrow tips to axes extend axes a bit at the start and/or end have invisible axes highlight the area between two curves
1. ThreeDScene now supports 3dillusion_camera_rotation
1. Add z_index for manipulating depth of Objects on scene.
1. Add a VDict class: a VDict is to a VGroup what a dict is to a list
1. Added Scene-caching feature. Now, if a partial movie file is unchanged in your code, it isn’t rendered again! [HIGHLY UNSTABLE We’re working on it ;)]
1. Most get_ and set_ methods have been removed in favor of instance attributes and properties
1. The Container class has been made into an AbstractBaseClass, i.e. in cannot be instantiated.  Instead, use one of its children classes
1. The TextMobject and TexMobject objects have been deprecated, due to their confusing names, in favour of Tex and MathTex . You can still, however, continue to use TextMobject and TexMobject , albeit with Deprecation Warnings constantly reminding you to switch.
1. Add a Variable class for displaying text that continuously updates to reflect the value of a python variable.
1. The Tex and MathTex objects allow you to specify a custom TexTemplate using the template keyword argument.
1. VGroup now supports printing the class names of contained mobjects and VDict supports printing the internal dict of mobjects
1. Add all the standard easing functions
1. Scene now renders when Scene.render() is called rather than upon instantiation.
1. ValueTracker now supports increment using the += operator (in addition to the already existing increment_value method)
1. Add PangoText for rendering texts using Pango.

## Documentation ¶

1. Added clearer installation instructions, tutorials, examples, and API reference [WIP]

## Fixes ¶

1. Initialization of directories has been moved to config.py , and a bunch of bugs associated to file structure generation have been fixed
1. Nonfunctional file media_dir.txt has been removed
1. Nonfunctional if statements in scene_file_writer.py have been removed
1. Fix a bug where trying to render the example scenes without specifying the scene would show all scene objects in the library
1. Many Exceptions have been replaced for more specific exception subclasses
1. Fixed a couple of subtle bugs in ArcBetweenPoints

## Of interest to developers ¶

1. Python code formatting is now enforced by using the black tool
1. PRs now require two approving code reviews from community devs before they can be merged
1. Added tests to ensure stuff doesn’t break between commits (For developers) [Uses Github CI, and Pytest]
1. Add contribution guidelines (for developers)
1. Added autogenerated documentation with sphinx and autodoc/autosummary [WIP]
1. Made manim internally use relative imports
1. Since the introduction of the TexTemplate class, the files tex_template.tex and ctex_template.tex have been removed
1. Added logging tests tools.
1. Added ability to save logs in json
1. Move to Poetry.
1. Colors have moved to an Enum

## Other Changes ¶

1. Cleanup 3b1b Specific Files
1. Rename package from manimlib to manim
1. Move all imports to __init__ , so from manim import * replaces from manimlib.imports import *
1. Global dir variable handling has been removed. Instead initialize_directories , if needed, overrides the values from the cfg files at runtime.
